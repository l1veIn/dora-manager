## 核心成果

**SDK 全链路在真实 dataflow 中验证成功。** 从 HTTP API 启动 dataflow → transpiler 注入 DM_RUN_ID → dora coordinator spawn 节点 → 节点通过 SDK 读写 dm-server → 外部 SDK 也能正常交互。

### 数据流
```
HTTP POST /api/runs/start (demo-sdk-interaction.yml)
  → dm-core transpile: node: dm-sdk-demo → path: ~/.dm/nodes/dm-sdk-demo/.venv/bin/dm-sdk-demo
  → inject_runtime_env: DM_RUN_ID / DM_NODE_ID / DM_RUN_OUT_DIR 写入 env:
  → dora start transpiled.yml → coordinator spawns / spawns node
  → node reads DM_RUN_ID → dm.Message() initializes → works
  → node subscriber_loop polls Web UI input → reverses → sends back
```

### 技术问题排查
- **release binary 过旧**：3月22日的 release binary 没有 `inject_runtime_env` pass，导致 transpiler 不输出 env，节点拿不到 `DM_RUN_ID`
  - 解决方案：用 debug build (`cargo build -p dm-server`) 启动，debug 包含了最新的 transpile 代码
- **`pip install` 两次**：节点 `.venv` 里需要安装 SDK (`dm` 包)
- **hermes venv 没有 dm 包**：需要 `uv pip install -e sdk/python/`
